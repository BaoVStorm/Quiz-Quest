Tựa game này là một dự án được làm trong quá trình học Unity từ **Udemy**.

Khoá học trên undemy: **Complete C# Unity Game Developer 2D**

Tựa game này là nơi đấu trí với những câu hỏi về nhiều lĩnh vực, tập trung cao để nhận được nhiều điểm nhất có thể

# 📖 Những gì học được từ dự án

- Thuần thục và làm quen được các thao tác trên UI

- Xử lý các sự kiện, các quan hệ trên UI:
  - Canvas
  - TextMeshPro
  - Button
  - Image
  - Slider
 
- Chuyển cảnh (load scene)

- Cách quản lý dữ liệu trên 1 dự án:
  - ScriptableObject
 
- Đưa font, tạo font mới vào project

- Kỹ năng lập trình, code logic rành mạch

- Kỹ năng debug và khả năng tư suy sâu

- Kỹ thiết kế vẽ giao diện cho dự án
